# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful, welcome newcomers, give constructive feedback, and assume good intent.
Not tolerated: harassment, discrimination, personal attacks, doxxing, or sexualized language and imagery.

**Reporting:** open a private report via GitHub (Security tab → "Report a vulnerability" works for conduct
issues too) or contact the maintainers listed in [CODEOWNERS](.github/CODEOWNERS). Reports are kept
confidential. Maintainers may warn, temporarily ban or permanently ban contributors, per the Covenant's
enforcement guidelines.
