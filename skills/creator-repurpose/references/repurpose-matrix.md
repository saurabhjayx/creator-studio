# Repurpose matrix

Which atom from the source fits which format. Specs (length, aspect, limits) live in
`skills/creator/references/platforms.md`.

## Atom → format fit

| Atom type | Short video | Carousel | LinkedIn | X thread | Newsletter | Pinterest | Quote card |
|-----------|:-----------:|:--------:|:--------:|:--------:|:----------:|:---------:|:----------:|
| Single surprising insight | Best | ok | ok | ok (post 1) | ok | - | Best |
| Step-by-step / how-to | ok (3 steps max) | Best | ok | Best | ok | Best | - |
| List (tools, mistakes, tips) | ok (top 3) | Best | ok | Best | ok | Best | - |
| Personal story / turning point | Best | - | Best | ok | Best | - | ok |
| Opinion / contrarian take | Best | ok | Best | Best | ok | - | Best |
| Data point / stat (from source) | Best (on-screen) | ok | ok | ok | ok | ok | Best |
| Before/after | Best | Best | ok | - | - | Best | - |
| Framework / model | ok | Best | Best | Best | ok | ok | - |
| Mistake + fix | Best | Best | ok | ok | - | ok | ok |
| Quote from guest/expert | ok | - | ok | ok | ok | - | Best |

## Source type → strongest outputs

| Source | Mine first | Watch out for |
|--------|-----------|---------------|
| Blog post | Headers → carousel slides; H2 claims → shorts; intro story → LinkedIn | SEO filler, keyword-stuffed phrasing |
| Podcast transcript | Strong guest quotes, stories, disagreements → shorts + quote cards | Rambling; tighten every line, keep meaning |
| Video script | Each section = a short; B-roll ideas carry over | Callbacks to "earlier in this video" |
| Long LinkedIn/X post | Core opinion → shorts; list → carousel | Already short; fewer assets, not padded ones |
| Notes / outline | Structure → carousel + thread | Missing specifics; mark `[add example]` |

## Native rewrite rules per platform

| Platform | Rewrite as | Not as |
|----------|-----------|--------|
| Reels / TikTok / Shorts | Spoken, present tense, one idea, visual cue per beat | Read-aloud blog paragraph |
| Carousel | One idea per slide, <= 25 words, numbered progression | Wall of text screenshots |
| LinkedIn | First-person, lesson learned, short lines, a stance | Press release, link-first |
| X thread | Punchy claims, each post standalone, numbers up front | Blog chopped every 280 chars |
| Newsletter | Personal note, why-it-matters, one link | Full article again |
| Pinterest | Search-keyword title, benefit, evergreen phrasing | Dated/news phrasing |
| Quote card | <= 20 words, attributed, high contrast | Paraphrase that changes meaning |

## Spacing cross-posts

- Same video across Reels/TikTok/Shorts: stagger 4-24h, remove watermarks, re-cut first second if possible.
- Text: LinkedIn and X on different days; newsletter after at least one social asset tests the angle.
- Lead with the asset whose atom is strongest; use its response to pick the next.
